# Phase 1 clinical review package

## General Ophthalmology template v2

Phase 1 now provides a published, versioned General Ophthalmology template covering:

1. Presenting complaint, onset, ocular history, systemic history, medication and allergy review
2. Review of the saved visual-acuity, pressure, and refraction workup
3. Bilateral anterior-segment findings
4. Bilateral posterior-segment, optic-disc, and motility findings
5. Conditional investigation details
6. Diagnosis, management, outcome, recall, referral, and surgery-planning details
7. Role-specific nursing and optometry handoff fields

The template is assigned as the Ophthalmology fallback for general, new, and follow-up encounters. Existing Doctor Events remain linked to the exact template version on which they were created.

## Hospital acceptance checklist

A nominated ophthalmologist and clinical operations representative should review the published baseline in **Administration > Examination templates** and record requested changes as a new draft version.

- Confirm the order and wording of each section.
- Confirm which fields are required.
- Confirm OD and OS laterality for each examination field.
- Confirm doctor, nurse/technician, and optometrist visibility using the role preview.
- Test every conditional field:
  - Workup interpretation
  - Requested investigations
  - Recall interval
  - External referral details
  - Surgery-planning notes
- Confirm the visit-outcome options.
- Confirm that a draft can be saved without affecting active encounters.
- Confirm that publishing is irreversible and creates a permanent version.
- Confirm that an existing draft or signed Doctor Event remains pinned to its original version.
- Complete one new-patient and one follow-up consultation on an iPad-sized screen.
- Review the signed snapshot and PDF output for completeness.

## Acceptance record

Record the following outside source control or in the hospital's approved change-management system:

- Reviewer names and roles
- Template code and version
- Review date
- Accepted changes or requested amendments
- Approval decision
- Effective date

Hospital acceptance is a deployment checkpoint. Requested field changes should be made through a new template version; published versions and signed clinical records must not be edited in place.
